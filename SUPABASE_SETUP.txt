MEC OSH SUPABASE ACTIVATION

1. In Supabase SQL Editor, run supabase/schema.sql if not already completed.
2. Run supabase/security-setup.sql.
3. Authentication > Users: create/confirm muhammed.shamil@mecemirates.com.
4. Authentication > Email Templates > Magic Link: use {{ .Token }} in the email body so a numeric OTP is sent.
5. Authentication > URL Configuration:
   Site URL: https://mec-osh-department.github.io/sama-yas/admin/
   Redirect URL: https://mec-osh-department.github.io/sama-yas/admin/
6. Upload all website files to the root of the GitHub repository.
7. Open https://mec-osh-department.github.io/sama-yas/admin/ and click Send OTP.

SECURITY
- The website includes only a publishable key, which is intended for browser use with RLS.
- Never place a Supabase secret/service-role key in GitHub Pages.
- Rotate the secret key that was previously exposed.


ADMIN LOGIN UPDATE
------------------
The Admin Dashboard now uses email-and-password authentication.

In Supabase:
1. Open Authentication > Users.
2. Make sure muhammed.shamil@mecemirates.com exists.
3. Assign a strong password to that user. If the existing user has no known password,
   delete it and create it again using Add user, with Auto Confirm enabled.
4. Open the website /admin/ page and sign in with that password.

Do not place the password, secret key, or service_role key in website files.
